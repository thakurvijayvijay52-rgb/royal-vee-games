# Royal Vee Games — Website Starter

This is a mobile-friendly **front-end starter website** for Royal Vee Games.

## Included
- Home page
- Reels placeholder cards
- Results publishing placeholder
- Admin login screen (visual demo only)
- Subscription QR placeholder

## Important before publishing
This starter does **not** include a secure admin backend, database, video hosting, real results feed, or payment verification. Do not enter real admin passwords or collect payments through this demo. A developer must connect secure authentication and storage before using the admin area.

UPI/QR payments should only be used for lawful subscriptions or services, not betting or wagers. Follow applicable Indian laws and platform rules.

## Preview on a computer
Open `index.html` in a browser.

## Next build steps
1. Choose hosting for the website.
2. Add secure admin authentication and a database.
3. Add authorized reel/video links and verified informational updates.
4. Add a verified business UPI QR only for lawful subscriptions.
5. After the website is tested, package it as an Android app.

This project is a starting template, not a finished production app.
