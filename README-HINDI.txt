# Royal Vee Games — PWA package

## Files
- `index.html` — complete responsive app demo
- `manifest.json` — PWA install metadata
- `sw.js` — offline cache service worker
- `icon.svg` — black-and-gold app icon

## Put it on GitHub Pages
1. Open your repository: `royal-vee-games`.
2. Upload all four files from this folder to the repository root (same level as README.md).
3. Commit the changes.
4. Open the GitHub Pages URL and refresh it.

## Important before real public launch
This is a **front-end demo**, not a production backend. Login, membership, posts and UPI settings are saved only in the current browser using local storage. They do not sync between phones and are not secure. The admin screen is a demo and has no secure password. Do not collect real payments or personal information through this demo.
For a live service, connect secure server-side authentication, database, admin authorization, media storage, and a verified payment provider/webhook. Membership plans shown here are content-access examples only; no betting, cash wagering, or cash prizes are implemented.
